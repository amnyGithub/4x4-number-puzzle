# 4×4 Number Puzzle

A polished, self-contained 15-puzzle style browser game.

## Play

Open `index.html` directly in a browser. No build step, server, external library, or internet connection is required.

## Features

- 4×4 board with numbers 1–15 and one empty space
- Solvable puzzle generation
- Easy, Normal, Hard, and Expert difficulty
- Move counter and timer
- Best-move records saved in browser local storage
- New Game and Shuffle controls
- Undo and Hint
- Pause/Resume
- Arrow-key controls plus touch/click controls
- Animation speed settings
- Sound on/off
- Ocean, Purple, Forest, and Sunset themes
- Responsive mobile-friendly layout

## GitHub Pages

To publish the game as a website, enable GitHub Pages for the repository and use the `main` branch as the deployment source.
